# T6 — Report, statistics, suggestions, `apply`, `export`

Prerequisites: T1–T5 merged. Read `core/src/{types,config,store,lifecycle}.ts` and spec §9, §11.

## Scope (files you own)
- `core/src/stats.ts`, `core/src/report.ts`, `core/src/apply.ts`, `core/src/export.ts`, `core/src/commands/report.ts` (replace stub body)
- `core/test/stats.test.ts`, `core/test/report.test.ts`, `core/test/export.test.ts`

## Requirements
1. `stats.ts` (pure, no deps): `mean`, `variance` (sample), `quantile(xs, q)`, `welchT(a, b): {t, df, p}` (two-sided; implement the Student-t CDF via the regularised incomplete beta function — write it, ~40 lines; test against known values with 1e-3 tolerance), `logCostCI(a, b, alpha): {ratio, lo, hi}` (ratio = exp(mean(log a) − mean(log b)) with CI from Welch SE and t-quantile — implement the inverse t by bisection on the CDF), `mdd(nA, nB, pooledSdLog, alpha, power): number` = relative difference `exp((z_{1−α/2}+z_{power})·sd·sqrt(1/nA+1/nB)) − 1` using the normal quantile (Acklam approximation or bisection on erf). Export `normalQuantile`.
2. `report.ts` — `buildReport(store, policy, pricing, opts: {since: Date, by?: "label", now: Date}): Report` producing a JSON object with sections 1–6 of spec §9 in this exact key order: `header`, `arms` (array, one per arm or a single `"all"` arm when the experiment is off), `strata` (by `analysis_label`), `targets`, `detectability`, `alerts`, `suggestions`. Follow every definition in §9 (quality weights redistribution, CPAT, 性价比, n < 8 → `insufficient: true`, style suspicion, acceptance overhead alerts, three deterministic suggestion rules). Classifier latency p50/p90 from `route.decided`. `renderMarkdown(report): string` — compact tables, Chinese/English bilingual headers as in PRD §5 (e.g. "总表 / Summary"). Include a one-line explanation of MDD under the detectability table.
3. `apply.ts` — `applySuggestion(home, reportFile, n, arm?)`: reads the saved report JSON, finds suggestion `n` (1-based), loads the target policy file (top-level, or `experiment.arms[arm]`), sets `field` (a JSON-pointer-like dotted path such as `preferences.per_label_bias.mechanical.dsh`) to `to` **only if the current value still equals `from`** (else error `stale`), writes YAML back preserving the document's other content (use `yaml` `parseDocument`/`setIn` so comments survive), returns `{field, from, to, policy_version}`.
4. `export.ts` — `exportJsonl(store, since)` writes one event per line; `exportOtel(store, since)` writes OTLP-JSON `resourceLogs` with one log record per event (`body` = JSON string of payload, `attributes` = envelope fields, `timeUnixNano`). No network.
5. Commands: `report [--since 14d|ISO] [--by label] [--format md|json] [--out FILE]` (always also saves `$EVENER_HOME/reports/<ISO ts>.json` and prints its path in `header.saved_to`), `apply <n> [--arm A] [--report FILE]` (default = latest file in `reports/`), `export --format jsonl|otel [--since]`.
6. Tests: seed a temp store with a deterministic synthetic dataset (write a `seed()` helper: 2 arms × 3 labels × ~12 tasks with controlled costs and verdicts; use a seeded PRNG, e.g. mulberry32), then assert: CPAT equals the hand-computed value for one cell; a cell with n = 5 is `insufficient`; quality score redistributes weights when there is no feedback; style suspicion triggers in a constructed case; the MDD shrinks when n doubles; suggestion rule 1 fires for a constructed label gap and `apply` changes exactly that key and nothing else (compare YAML before/after minus the key; comments preserved); `apply` with changed `from` errors `stale`; `exportJsonl` line count equals event count; `welchT` on two known samples matches a reference p within 1e-3; `normalQuantile(0.975) ≈ 1.95996`.
7. `npm test` green.
